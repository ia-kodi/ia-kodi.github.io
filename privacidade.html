Política de privacidade do IA-Kodi

Última atualização: 1º de novembro de 2026.

O IA-Kodi é um assistente de voz pessoal e não comercial para o Kodi, que roda no computador de casa do próprio usuário. Esta página explica quais dados ele acessa, para quê e como o usuário pode revogar o acesso.

Os dados que o IA-Kodi acessa

Com a autorização do usuário pelo Google, o IA-Kodi usa a API de Dados do YouTube com a permissão https://www.googleapis.com/auth/youtube.readonly, somente para leitura. Ele lê:

  • a identificação do canal do usuário (para conferir que a conta conectada é a certa);
  • as playlists do usuário, as inscrições e os vídeos marcados com "gostei".

O IA-Kodi nunca publica, apaga ou altera nada na conta do YouTube.

Para que os dados são usados

Só para mostrar esses itens na tela e tocá-los no Kodi do próprio usuário, quando ele pede pela voz.

Onde os dados ficam

  • Não há servidor do IA-Kodi. Os dados ficam no computador do usuário.
  • A autorização do Google (o token) fica guardada nesse computador, cifrada pelo Windows para o usuário do Windows.
  • Para entender um comando de voz, o IA-Kodi envia o texto do comando e os títulos que estão na tela naquele momento (que podem incluir títulos de vídeos e playlists) ao serviço de inteligência artificial que interpreta o pedido (a OpenAI). Isso serve só para atender o próprio pedido do usuário.

Compartilhamento

Os dados não são vendidos, não são usados para publicidade e não são compartilhados com terceiros, além do que está descrito acima para atender o pedido do usuário.

O uso e a transferência das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions. Ao revogar, o IA-Kodi deixa de ler a conta, e a autorização guardada no computador deixa de valer.
